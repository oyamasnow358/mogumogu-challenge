# 😋 もぐもぐチャレンジ

給食で **苦手なものを ひとくち たべるごとに ⭐ がたまり、ゴールで ごほうび** がもらえる、特別支援教育向けの教材アプリです。
iPad の Safari で開くだけで使えます（ログイン・インストール不要）。

## しくみ（支援の考え方）

| 考え方 | アプリでは |
|---|---|
| **先に見通しを持たせる**（ファースト・ゼン） | はじめに「ピーマンを 3かい たべよう → できたら ごほうび」を見せる |
| **トークンエコノミー** | ひとくちごとに ⭐ がたまり、キャラクターが 🎁 に向かって進む |
| **自分で選ぶ** | ごほうびを子どもが 2〜4 この中から選べる（先生が決めることも可） |
| **スモールステップ** | 「さわる → においを かぐ → なめる → くちに いれる → たべる」から選べる |
| **すぐにほめる** | 効果音・ほめ言葉の読み上げ・演出がその場で出る |
| **続ける楽しみ** | クリアするとシールがもらえ、シールちょう（30しゅるい）が埋まっていく |

## 使い方（先生）

1. iPad の Safari でこのアプリの URL を開き、共有ボタン →「ホーム画面に追加」。
2. 右上の ⚙️ を **1.5秒ながおし** して先生用せっていを開く。
   - **だれの せってい？**：子どもを追加（ニックネーム＋動物マーク）。2人以上いると最初に「だれ？」画面が出ます。
   - **きょうの チャレンジ**：食べ物・回数・ステップ（たべる／なめる など）を決める。今日の献立の写真も撮って使えます。
   - **ごほうび**：子どもが選ぶ／先生が決める／シールだけ。写真つきの自作ごほうびも作れます。
   - **おと・ひょうじ**：声・効果音・音量、ながおしでカウント（うっかりタッチ防止）、演出ひかえめ（感覚過敏の子に）。
3. 子どもが「はじめる！」→ ひとくち食べたら大きな「たべた！」ボタン。

- 数えまちがえたときは、画面左下の「↩ ひとつ もどす」を**ながおし**。
- 途中でアプリを閉じても、同じ日なら続きから再開します。
- 設定・写真・シールはその iPad の中だけに保存されます（別の iPad へは「バックアップ」で移せます）。
